# Portfólio Resumo Profissional - Carlos Soares

Este projeto é uma página de resumo profissional dinâmica e interativa, desenvolvida originalmente durante o evento **"Semana do Zero ao Programador Contratado"** da **Dev Em Dobro**.

O projeto foi totalmente personalizado para refletir minha identidade visual e atuação profissional como Engenheiro de Computação e Desenvolvedor Full Stack.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização avançada e responsiva.
- **JavaScript (Vanilla)**: Lógica de navegação, efeitos visuais e interatividade.
- **Inteligência Artificial**: Imagens de fundo e ícones conceituais gerados via IA.
- **Photoshop**: Edição e composição das imagens para garantir a estética desejada.

## ✨ Diferenciais e Personalizações

Além da base do evento, implementei diversas melhorias para tornar o site único e performático:

- **Navegação Dinâmica**: Troca de seções ("cards") através de cliques nos botões laterais ou pelo scroll do mouse/trackpad, proporcionando uma experiência fluida.
- **Efeito de Digitação (Typing Effect)**: Na tela inicial, meus cargos e especialidades são exibidos com uma animação de digitação em tempo real.
- **Efeito Glitch Digital**: Aplicado em títulos de seções específicas para reforçar a estética tecnológica ("cyberpunk/GTA") do portfólio.
- **Alternância Automática de Títulos**: O título da seção de Desenvolvimento Web alterna dinamicamente entre diferentes stacks (Full Stack, Python, PHP, etc) com o efeito glitch.
- **Otimização de SEO**:
    - Configuração completa de Meta Tags (Open Graph, Twitter Cards).
    - Implementação de `robots.txt` e `sitemap.xml`.
    - Estrutura focada em indexação para o domínio `carlossoares.dev`.
- **Botão Flutuante WhatsApp**: Integrado ao sistema de navegação para facilitar o contato.
